Opens fast, stays out of your way.

A browser for Windows and Android that keeps your history, passwords and bookmarks in a folder you can see. No account, no sync, nothing uploaded.

Windows

A small installer that fetches the current build, checks it, and puts Feather in your own user folder. No admin password needed. The same file runs on Windows 7 SP1 through 11; extensions need Windows 10 or 11, since 7 stops at an engine without them.

Android

The newest signed APK, downloaded straight from the release page. Android will ask you to allow installs from this browser the first time.

Your data stays put

History, bookmarks, saved logins and settings live in a Feather folder on the machine. Nothing is sent anywhere.

Ads filtered at the door

Requests to ad and tracker hosts are dropped before the page loads them. There is no subscription and no allow-list.

No Feather account

There is no sign-in, so there is nothing to leak. Moving to another computer is a file you carry yourself.

Feather is a work in progress. The Android build has tabs, settings, ad blocking and the music bar; bookmarks and passwords are still coming. Both files are served from GitHub Releases.
