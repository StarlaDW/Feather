# Feather

A closed-source, lightweight browser for Windows.

This repository hosts **release downloads only**. The Feather source code is not
published here.

## Download

Grab the latest `FeatherSetup.exe` from the [Releases](../../releases/latest) page.

- The setup wizard installs Feather into `%LOCALAPPDATA%\Programs\Feather`.
- Uninstall any time from Windows Settings → Apps, or by running
  `Feather.exe --uninstall`.
